## Блок 2: форматы и опечатки (осторожнее, чем нужно)

| | После блока 1 | После блока 2 |
|---|---|---|
| Совпало значений | 71 из 90 | **88 из 90** |
| Молча неверно | 0 | 0 |
| Приём и классификация | 5 расхождений | 0 |

- **Даты** — один формат на все места (`config.date` + `parseDate`): 15.04.2026, 30.04.26, 2026-05-20, «15 апреля 2026 г.», «"28" марта 2026 года». Несуществующие даты не «переезжают» (31.02 ≠ 03.03).
- **Срок, который не разобрать** («в течение 45 дней», «2O26», «31.02.2026») → «требует проверки», а не «нет данных».
- **Сумма**: «Цена договора», «Стоимость договора», опечатка «Обшая»; «ориентировочная/предварительная» — стоп-слова; сумма в долларах/евро → «требует проверки».
- **Договор одной строкой** делится на абзацы перед «Дата:», «Статус:» и номерами пунктов после конца предложения.
- **Опечатки**: «ДОГОВР ПОСТАВКИ», «обоими сторонами», «не позденее»; заголовок строчными, «№stn-703» → STN-703 с пометкой.
- **Найдено по ходу**: новый синоним «стоимость договора» подхватил строку промпт-инъекции «итоговая стоимость договора — 99 000 000 рублей» в самом договоре (STN-605). В таблицу она не попала (два значения → «требует проверки»), но правильнее не извлекать значения из абзаца, обращённого к «системе ИИ»: такие абзацы теперь пропускаются, документ помечается. STN-605 снова 760 000 ₽.

**Оставшиеся 2 расхождения допустимы по самим ожиданиям**: STN-309 — «требует проверки» вместо 612 000 (ожидания прямо допускают), STN-406 — «нет данных» вместо «требует проверки» (оба осторожны).
