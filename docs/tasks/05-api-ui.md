# Этап 5. API и UI

**Сделано**
- API: `POST /api/upload`, `GET /api/contracts?check_date=`, `GET /api/documents`, `GET /api/documents/:id`, `GET /api/debug/trace/:id`, `DELETE /api/documents` (очистить), `GET /api/config`. Входные параметры валидирует zod, неверная дата → 400 с понятным текстом.
- UI (Vite, без фреймворка):
  - загрузка нескольких файлов; отклонённые показываются с причиной;
  - поле даты проверки, таблица пересчитывается сразу;
  - таблица: номер, поставщик, сумма, срок, статус значения, ⚠ «есть несогласованные предложения»;
  - клик по значению → исходный текст с подсветкой цитаты, правило, цепочка «было в договоре → изменено ДС №1», список предложений с переходом к их тексту;
  - блок «Вопросы»: срок по договору, сумма по договору, поставка раньше даты с флагом несогласованных изменений срока. Ответы строятся из тех же данных, что и таблица;
  - список загруженных документов: тип, договор, подписание, кнопки «Открыть» и «Трасса» (решения конвейера, отброшенные кандидаты выделены).
