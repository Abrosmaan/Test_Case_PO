# Этап 1. Приём и сегментация

**Сделано**
- `src/pipeline/ingest.ts`: проверка расширения `.txt`, размера ≤ 1 МБ, бинарного содержимого, пустого файла; декодирование UTF-8 (строгое), иначе cp1251. BOM убирается, переводы строк приводятся к `\n` — сохранённый текст единственный источник смещений.
- Дедупликация по sha256 нормализованного текста: тот же файл под другим именем → `duplicate`, новый документ не создаётся.
- `src/pipeline/segment.ts`: одна непустая строка = абзац; `clause_no` (`2.1`, `3`, null), `line_no`, `start`, `end`.
- `src/pipeline/process.ts`: батч с `batch_id`, ошибка одного файла не роняет остальные.
- `src/pipeline/trace.ts`: каждое решение → лог (с `batch_id`, `document_id`, `stage`, `rule_id`, длительность) и таблица `trace`.
- SQLite (`node:sqlite`), схема создаётся идемпотентно. `POST /api/upload` (multipart), минимальная форма загрузки в UI с причинами отказа.

**Как проверить руками**
`npm run dev`, открыть http://127.0.0.1:5173, загрузить `Test Files/*.txt` и любой PDF — PDF отклонён с причиной, остальные приняты; повторная загрузка → «уже загружен».

**Не решено**
- Абзац = строка: для тестовых файлов это верно; многострочные пункты пока не склеиваются.
