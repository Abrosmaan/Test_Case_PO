# Расширенный набор Test Cases: молча неверные значения

`npm run cases` прогоняет 80 документов из `Test Cases/cases` одной пачкой на дату 10.03.2026 и сверяет с `Test Cases/expected.json`. Расхождения делятся на три класса:
- **молча неверно** — уверенное значение там, где ожидалось другое значение, «нет данных» или «требует проверки», либо лишняя строка без пометки (код выхода 1);
- **осторожнее, чем ожидалось** — «нет данных» или «требует проверки» вместо значения (не ошибка, но потеря полноты);
- **приём и классификация документов**.

|---|---|---|
| Совпало значений | 63 из 90 | 71 из 90 |
| Молча неверно | 9 (+ лишние строки «STN», «STN-7») | **0** |

**Что было молча неверно и как исправлено**

| Кейс | Было | Причина | Стало |
|---|---|---|---|
| STN-211 «1.200.000,00 руб.» | 0 ₽ | точка как разделитель тысяч не поддерживалась, сумма бралась из хвоста «000» | 1 200 000 ₽ |
| STN-705 «1 200 00 0 рублей» | 0 ₽ | шаблон суммы начинался с середины числа | требует проверки с цитатой |
| «STN-7O9», «STN 705» | строки «STN-7», «STN» | номер обрезался на середине / до пробела | «STN-7O9» как написан, «STN-705» — оба с пометкой «требует проверки» |
| STN-704, ДС с кириллической «Т» | 2 900 000 ₽ «действует», ДС потеряно | номер ДС не совпадал с договором | ДС привязано через нормализацию двойников (только при смешении алфавитов), но не применено молча: сумма «требует проверки», 3 050 000 — предложение |
| STN-304, ДС без даты вступления | 287 000 «действует» | сомнительное ДС помечало договор, но не поле | сумма «требует проверки» |
| STN-309, «ПРОЕКТ» + «подписано» | 612 000 «действует» | то же | сумма «требует проверки» |
| STN-306, два ДС в один день | 830 000 (ДС №2) | побеждал бо́льший номер | «требует проверки: … вступают в силу в один день и задают разные значения» |
| STN-310, «в пункте 3.1 слова «A» заменить словами «B»» | 15.04.2026 «действует» | нераспознанный пункт искал поле только по словам | поле ищется и по номеру пункта → срок «требует проверки» |
| STN-606, неподписанный договор | значения «действуют» | статус подписания договора не учитывался | значения проектные, «требует проверки» |
| Два договора в одном файле | первый как обычный | — | «требует проверки: в одном файле несколько договоров» |
| PNG, переименованный в .txt | принят | в заголовке PNG нет NUL-байтов | отклонён: любые управляющие символы, кроме табуляции и переводов строк |

Каждый случай закреплён синтетическим тестом в `tests/silent-wrong.test.ts` — не зависит от папки `Test Cases`.

**Осталось (осторожнее, чем ожидалось — 19 значений)**: даты прописью, ISO и с двузначным годом, «цена договора», договор в одну строку, опечатки в заголовке («ДОГОВР», «обоими»), номер в нижнем регистре. Прототип отвечает «нет данных» и не выдумывает, но эти значения можно извлекать.
