# Этап 3. Экстракторы полей

**Сделано**
- Реестр `src/extractors/index.ts`: `supplier`, `total_amount`, `delivery_date`. У всех один интерфейс `extract(segments) → { facts, noData, rejected }`.
- `buildSegments`: для договора, проекта и письма — все абзацы; для ДС — только текст в кавычках из «Пункт X.Y договора изложить в следующей редакции: «…»», факт получает `replaces_clause = X.Y`. Остальной текст ДС условия не меняет, его не извлекаем.
- Сумма: денежная сумма в пункте с «общая стоимость» без стоп-слов (аванс, лимит, бюджет, срок оплаты, неустойка, штраф). Есть «общая стоимость», но нет суммы → `no_data`, причина — цитата пункта.
- Срок: «поставить … не позднее DATE» или «срок поставки (с DATE) на DATE»; стоп-слова «оплат», «приемк».
- Отброшенные кандидаты с причиной идут в трассу, а не в таблицу (например, «252 000 ₽ — «аванс» — не общая стоимость»).
- Цитата факта — весь пункт или новая редакция; инвариант `source.slice(start, end) === quote` проверяется тестом.

**Решения**
- Значения из проектов и писем извлекаются теми же экстракторами. Что с ними делать (предложение, а не условие), решает этап 4.

**Не решено**
- Сумма прописью не сверяется с цифрами.
